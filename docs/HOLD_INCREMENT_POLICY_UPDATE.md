# V8 接触保持与增量策略（2026-11-04）

V7 的三次实测均在752步失败。首回合在545步开始偏离成功V4对照；546步起，原teacher要求保持上一接触目标，但这个目标距仍在移动的V4基准约0.009449rad，超过0.006rad的指关节残差范围。共有297个原专家投影标签无法由旧结构表达。这是动作表示限制，单纯增加训练轮次不能解决。

V8保留冻结V4、同一284维实际观测和GRU历史，让每个左关节学习三种动作。BASE输出冻结基准；HOLD输出上一实际施加目标；UPDATE对11个恢复手指关节输出相对上一目标的有界增量，其余关节仍输出相对基准的有界修正。原环境的float32动作转换、软限位、速度投影、碰撞和接触阶段验收全部保留，HOLD不再受“距移动基准0.006rad”限制。

训练标签来自原实际执行空间：与BASE逐位相等优先记BASE，其次与HOLD逐位相等记HOLD；其余距两者均大于1e-6rad才进入确定UPDATE分类。模糊值只不进入分类损失，全部原连续目标保留。actor不接收专家隐藏状态或标签，也没有硬编码接触阈值控制器。

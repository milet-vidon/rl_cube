# 先完成可控转动，再训练与接入视觉复原

用户于 2026-11-03 明确顺序：先实现魔方自由转动，然后训练具备该能力的模型，最后结合视觉与魔方公式自动复原。此顺序优先于此前 BC 对照队列；已经完成的 checkpoint 保留。等待中的 v10 闭环评估已取消，当前只继续物理转层开发。

## 第一阶段：能可靠执行解法所需的物理动作

自由转动的工程目标是：左手稳定支撑，右手执行目标层转动；能完成六个面正反向 90° 和 180° 动作，并通过必要的整块换面、重抓把动作连续组合起来。整块魔方换姿与单层转动分别记录和验收。

推进顺序：

1. 当前 nZ 面 15° 接触转动及稳定保持通过，再扩展 30°、90°；禁止仅凭指令角度判定成功。
2. 扩展反向转动与 180°。目前 CLI 只接受正向的 15/30/90° 探索目标，负向与 180° 尚未实现，必须补齐符号、路径和层测量测试后运行。
3. 验证整块换面、右手重新接抓；根据完整 IK、碰撞和实测结果决定是否需要分段转动/重抓。
4. 将六面的动作映射到机器人可达的操作面，验证连续动作、逆动作、反复换面和误差累积。控制器与参数冻结后，另选未见过的种子进行独立评估。

本阶段保留现有 56 DOF、软硬限位交集、速度、碰撞、接触和任务门禁。每次从真实仿真 reset 开始，不绑定魔方，不给魔方施加目标驱动或在控制中重置其位姿。当前转层验收沿用 `opposed_grasp_audit.py` / `layer_turn_metrics.py`：目标层九块实际相对旋转、非目标层与离轴运动、两手接触、掌腕肘姿态、位置与速度，以及连续合格保持时间。新能力采用新版本协议，保留已有冻结证据，不放宽旧门槛。

当前证据：右手五指保持 3.5 秒，目标面约 5.687°，15° 验收未通过；主要观察到转动中接触丢失和目标层较高角速度。`teacher_joint_right_traction_v4_20261103` 已完整执行 3239 步：左手居中通过，右手保持阶段五指接触比例为 100%，但 89/121 帧魔方角速度不低于 0.20 rad/s，连续合格保持仅 0.1 秒，原门禁阻止转层。该材质仅覆盖 77 个右手碰撞体，左手材质绑定未变。当前 `teacher_joint_right_compliance_v5_20261103` 保持同样摩擦，仅将右手 21 个指部关节刚度由 30 降至 20；在右手预检通过、开始接近前应用并归档，臂部增益、力矩限值及全部验收条件不变。完整物理效果仍待验证。理想刚性掌部轨迹在 0/15/30/45/60/90° 均满足当前掌向几何条件，但这只是离线几何分析，不能替代完整 IK、碰撞或 PhysX 验收。

## 第二阶段：训练可组合的操作技能

只有第一阶段形成可重复的成功操作后，才把验收通过且源码/资产/配置哈希完整的轨迹作为示范，训练目标条件策略。失败回合用于诊断，不能伪装成成功监督。

策略输入包含机器人关节位置/速度、上一动作与当前驱动目标、魔方位姿/目标层、接触与运动状态、当前动作阶段和目标转角；输出仍通过现有安全层转换成 56 维动作。策略学习持握、转层、换面和重抓的执行能力。评估必须在闭环中完成持握和实际层转动，离线 BC 误差不能替代物理成功率。teacher、带监督策略和纯 PPO 分别标注，是否启动后续 RL 仍受原门禁控制。

已有 v7/v10 是左手单示范 BC 候选，尚未通过完整闭环，不能当作已经具备自由转动能力的模型。后续训练输入需要动作目标和阶段，避免把不同面、方向、角度的目标混为一个无条件动作序列。

## 第三阶段：视觉状态与公式执行

现有接口已核对：`environment.py` 提供胸前 RGB 相机与观测读取，`camera_calibration.json` 明确标注为仿真标定；尚未发现完整的六面颜色状态识别或公式求解实现。后续复用相机入口，补齐状态识别与求解，不将已有 RGB 观测等同于已经完成视觉复原。

职责划分：

- 视觉估计器：输出带时间戳和置信度的魔方位姿、可见面颜色及遮挡信息；通过主动换面补全六面，建立 54 个面块的状态。
- 状态检查器：检查颜色、中心面的坐标约定和魔方状态合法性；识别不确定时重观察，不猜测后继续执行。
- 解法模块：根据已确认状态生成带方向的面转序列，例如 `R U R' U'`。具体求解库在本阶段再选择和验证，不要求低层策略记住整套公式。
- 动作映射器：结合当前魔方姿态，将规范面名和转数映射成已验收的换面/转层/重抓动作。整块换面更新坐标关系；层转动更新离散魔方状态。
- 执行与核验：每个动作完成后重新观测，比较预测状态与实际状态；不符时稳定持握、重观察并重新求解。只有视觉状态与机器人执行结果共同确认复原才报告成功。

接口边界采用现有分阶段执行方式：感知发布状态和置信度，解法模块发布离散动作目标，运动技能报告测得的转角、接触保持与失败原因。解法模块不能直接绕过技能控制器向关节发送指令。相机处理不阻塞当前控制循环，记录观测、目标、命令和结果的时间戳，确保之后可以回放和训练。

当前工作仍是 Isaac/PhysX 仿真。视觉闭环、完整解法执行和实体机器人迁移都尚未验收；各阶段以对应的真实结果为准。

本轮新控制项通过 19 项相关离线测试（含 3 项新增刚度参数/作用范围检查）及语法编译；v4 失败原始轨迹、源码和诊断已归档，v5 尚不计成功。

## 右手已进入实际转层

`teacher_joint_opposition_ring_v2_20261103` 共执行 3511 步。左手居中通过，右手五指共同合格保持 3.5 秒，随后进入 15° 转层。目标层九块的相对转角为 5.418–6.119°，面中心转角约 5.687°；其他块最大相对转动 1.987°，目标层最大离轴角 0.768°，最大关节原点分离约 0.146 mm。最终因 `opposed_face_turn_hold_gate_not_met` 失败，转层合格保持为 0 秒。

实际右掌转动约 14.797°，指令约 15.004°。转动过程中小指最先失去接触，之后食指和无名指失去接触，最终只剩拇指与中指；因此目前证据指向接触传递不足，不能仅归因为腕臂跟踪误差。左手食指也在转动时失去接触。左手接触点在魔方坐标系中的 z 为正，位置分析未发现左手接触目标 nZ 层，但这不是基于碰撞体 ID 的证明。目标层角速度在转动及保持时分别可达约 17.9 和 12 rad/s，还未达到稳定转层要求。

`trajectory.jsonl` 中通用记录器默认以 90° 计算误差；本次正确的 15° 指标以最终 `trajectory.json`、`opposition_contacts.jsonl` 和 `result.json` 为准。

`teacher_joint_traction_v3_20261103` 已完成 1992 步，在左手保持阶段因 `tilt_hold_timeout` 失败，未进入右手接近或转层。该实验：仅将手部接触材质设为静/动摩擦 1.2/1.0，魔方内部材质仍为 0.9/0.8。它是未标定的仿真对照，不代表真实材料参数，也未通过左手前置门禁。为消除对左手抓持材质的影响，新增 `--right-hand-friction`：通过初始化工厂在第一次 PhysX reset 前仅绑定右手碰撞体材质，检查左手材质绑定不变，记录实际绑定路径及参数；`teacher_joint_right_traction_v4_20261103` 已完成：左手居中通过，77 个右手材质绑定生效且左手未变，但高摩擦下角速度抖动使五指合格保持只有 0.1 秒，未进入转层。后续右手刚度对照与新的优先级见 CUBE_SOLVE_ROADMAP.md。源 MJCF 的关节 damping/frictionloss 与 USD 的刚体 angularDamping 不可当作等价参数；本轮没有添加魔方驱动或改动内部动力学来制造转动。

## 左手示范覆盖与腕肘恢复

新增 `--adaptive-wrist`，默认关闭。先尝试原规划器，再搜索相邻腕角；仍失败时联合求解左臂七关节。新求解器保留原掌位 2 mm、姿态 1° 误差限制，使用软/硬相交限位内的边界，并检查肘外展、腕位于肘内侧及腕侧弯方向。原安全与任务门禁文件未修改。

9901、9502、9503 的 baseline 新回合均在保持或腕部调整时遇到原 IK 失败；9901/9502/9503 的首轮自适应回合分别推进到第 1766/1644/1555 步后仍失败，未进入训练。历史 9801–9803 的重建失败请求可用相邻腕角复算通过，但不据此撤销历史实际失败。

9901 后续失败请求的联合求解复算：掌位误差 0.784 mm，姿态误差 0.454°，J6 为 6°，肘外展距离 0.16756 m、角度 35.641°。请求来自日志重建，不是完整回合成功证据。`teacher_coverage_9901_20261103_bounded_v3` 已完成 1776 步：成功越过原 IK 报错点，随后因原累计姿态校正上限 `Post-turn correction exceeded bounded pose envelope` 停止，合格保持仅 0.433 秒，仍未成为训练示范。

进一步分析 9901：多数保持窗口五指接触齐全，姿态误差约 1.3–1.9°，每 10 步的持续校正伴随 0.23–0.26 rad/s 的角速度峰值，略超过原 0.20 rad/s 验收线。新增可选 `--adaptive-wrist --settled-hold`，仅在测得误差不超过 2.5° 时停止姿态积分校正；仍执行原指部接触反馈、丢失接触处理、保持计数、超时及速度拒绝。任务姿态门槛仍为 5°，原累积校正上限仍保留。`teacher_coverage_9901_20261103_settled_v4` 已完整执行 1847 步，避免了累计姿态校正越界，但最终仍因 `tilt_hold_timeout` 失败，合格保持仅 0.2 秒。因此 v9 多示范训练没有启动；新示范覆盖仍未解决。

## 神经 teacher 训练与评估修正

`teacher_left_bc_applied_v7_20261103` 已完成 60000 次 BC 更新，训练耗时约 64.8 秒。使用已验收 seed 9501 示范的实际施加动作、0.005 rad 状态扰动和 BoxOutput；只有左手 28 维神经输出，右手仍使用记录的动作时序。同示范时间块验证 RMSE 为 **0.001725267 rad**，checkpoint 重载一致，SHA256 为 `704fa32e2ee9c58bd83958d51fb3eb1666807f1cbac1eb4b2b41a041ef14e9ec`。标签与旧候选不同，不能把误差直接当作公平的闭环提升比较。

发现并修正旧混合评估的混杂因素：9901 初始魔方位置相对 9501 相差约 3 cm，专家右手目标最大相差约 9.6°，旧评估却固定重放 9501 的右手目标。旧失败记录保留，但不能将全部失败归因于左手网络。新 `teacher_evaluation_sources.py` 要求右手示范通过验收、哈希和关节顺序检查，并匹配评估 seed；无匹配来源时明确拒绝。显式 legacy 标志仅用于复现旧诊断。评估现在归档实际源码、配置、资产契约和目标动作，并补齐专家在首次 tilt_hold 时将左手指部刚度切换到 20 的调度；右手使用示范中的实际施加目标。

v7 使用匹配的 9501 右手时序进行完整闭环开发评估。首次通过 run_linux.sh 启动被入口白名单拒绝，没有进入仿真；修正为当前 conda Python 直接启动，并在右手对照回合完成后串行重试。9901、9502、9503 均已见过，不再称为独立测试。首轮三种子的 baseline/自适应采集均未通过，因此 v6 多示范训练按规则没有启动。后续只在新增示范通过完整抓持/居中验收与证据校验时，训练 `teacher_left_bc_multiseed_v8_20261103` 并选择有匹配右手示范的 seed 评估。

## 右手已进入实际转层

`teacher_joint_opposition_ring_v2_20261103` 共执行 3511 步。左手居中通过，右手五指共同合格保持 3.5 秒，随后进入 15° 转层。目标层九块的相对转角为 5.418–6.119°，面中心转角约 5.687°；其他块最大相对转动 1.987°，目标层最大离轴角 0.768°，最大关节原点分离约 0.146 mm。最终因 `opposed_face_turn_hold_gate_not_met` 失败，转层合格保持为 0 秒。

实际右掌转动约 14.797°，指令约 15.004°。转动过程中小指最先失去接触，之后食指和无名指失去接触，最终只剩拇指与中指；因此目前证据指向接触传递不足，不能仅归因为腕臂跟踪误差。左手食指也在转动时失去接触。左手接触点在魔方坐标系中的 z 为正，位置分析未发现左手接触目标 nZ 层，但这不是基于碰撞体 ID 的证明。目标层角速度在转动及保持时分别可达约 17.9 和 12 rad/s，还未达到稳定转层要求。

`trajectory.jsonl` 中通用记录器默认以 90° 计算误差；本次正确的 15° 指标以最终 `trajectory.json`、`opposition_contacts.jsonl` 和 `result.json` 为准。

已排队 `teacher_joint_traction_v3_20261103`：仅将手部接触材质设为静/动摩擦 1.2/1.0，魔方内部材质仍为 0.9/0.8。它是未标定的仿真对照，不代表真实材料参数，仍需从 reset 重新通过全部前置门禁。源 MJCF 的关节 damping/frictionloss 与 USD 的刚体 angularDamping 不可当作等价参数；本轮没有添加魔方驱动或改动内部动力学来制造转动。

## 左手示范覆盖与腕肘恢复

新增 `--adaptive-wrist`，默认关闭。先尝试原规划器，再搜索相邻腕角；仍失败时联合求解左臂七关节。新求解器保留原掌位 2 mm、姿态 1° 误差限制，使用软/硬相交限位内的边界，并检查肘外展、腕位于肘内侧及腕侧弯方向。原安全与任务门禁文件未修改。

9901、9502、9503 的 baseline 新回合均在保持或腕部调整时遇到原 IK 失败；9901/9502/9503 的首轮自适应回合分别推进到第 1766/1644/1555 步后仍失败，未进入训练。历史 9801–9803 的重建失败请求可用相邻腕角复算通过，但不据此撤销历史实际失败。

9901 后续失败请求的联合求解复算：掌位误差 0.784 mm，姿态误差 0.454°，J6 为 6°，肘外展距离 0.16756 m、角度 35.641°。请求来自日志重建，不是完整回合成功证据。`teacher_coverage_9901_20261103_bounded_v3` 已完成 1776 步：成功越过原 IK 报错点，随后因原累计姿态校正上限 `Post-turn correction exceeded bounded pose envelope` 停止，合格保持仅 0.433 秒，仍未成为训练示范。

进一步分析 9901：多数保持窗口五指接触齐全，姿态误差约 1.3–1.9°，每 10 步的持续校正伴随 0.23–0.26 rad/s 的角速度峰值，略超过原 0.20 rad/s 验收线。新增可选 `--adaptive-wrist --settled-hold`，仅在测得误差不超过 2.5° 时停止姿态积分校正；仍执行原指部接触反馈、丢失接触处理、保持计数、超时及速度拒绝。任务姿态门槛仍为 5°，原累积校正上限仍保留。`teacher_coverage_9901_20261103_settled_v4` 已串行排队；只有该回合真正通过，才会训练 v9 多示范模型。

# CubeLab 魔方操作工作台

在仓库根目录另开终端运行：

```bash
conda activate rl_cube
bash run_cube_dashboard.sh
```

用本机浏览器打开 [训练监控](http://127.0.0.1:8765/#training)、[训练调参](http://127.0.0.1:8765/#controls) 或 [推理工作台](http://127.0.0.1:8765/#inference)。默认端口 8765；如有别的程序占用可加 `--port 8766`。关闭面板不会关闭长训。使用本机文件和服务，无需 npm、CDN 或公网。

**训练监控。** 每 5 秒读取选中实验的状态、当前采样日志、拟合记录、独立闭环验证和本机显卡遥测。短测与正式训练分列。采样的“曾拿稳”含 teacher 控制的环境；查看学生的表现用轮次表中的独立验证。没有验证时显示“—”。运行状态会检查主机上的文件锁，而非只相信可能残留的 `state.json`。

**远端训练。** 新增独立的 [远端训练入口](http://127.0.0.1:8765/#remote)，接入 Nexus-5090-1 的自然换姿与右手单层转动任务。原本机实验、轮次和模型保留在原页面。远端页显示独立实验选择、进程、GPU、采样进度、回合结果、PPO 更新、迭代验证和最近日志；每 5 秒刷新，断线时明确标注缓存。短测、更新前采样和更新后冻结验证分别标明，过程观测不计为最终成功。

该入口只读远端 JSON/日志，不启动、停止或修改远端训练，不下载 checkpoint。连接配置位于 `/home/brainco/rl_cube/work/remote_training_access/source.json`，也可用 `CUBE_DASH_REMOTE_CONFIG` 指定；私钥不在仓库内。远端使用专用 SSH forced-command 公钥，禁止终端和转发，只接受 `catalog`、`snapshot <允许的实验名>`。读取器独立于训练源码，使用标准库和 `nvidia-smi`，只读指定 runs 下 `r27_recipe*`、`r27_natural_face90*` 的实验。页面只监听本机回环地址。

R70 的[接触点比较](http://127.0.0.1:8765/?run=r27_recipe_contact_point_sweep70#remote)可直接打开。选点表用 C 组固定的 11 个种子比较首次合格食指触层和有效驱动，用全部 16 个种子检查是否新增不安全回合。结果为 `no_candidate` 表示两个偏移均未达到进入 PPO 的条件。页面同时显示后续 +15°、+90° 的前置条件；用户在 Nexus 启动对应实验后，可以在远端实验列表跟踪采样、冻结验证和独立验收。

**训练趋势与模型对比。** [训练趋势](http://127.0.0.1:8765/#trends) 看跨轮的拟合误差、相对父模型的权重变化和学生闭环达标率。[模型对比](http://127.0.0.1:8765/#compare) 则选同一实验的两个已验证轮次，在共同验证种子上分别统计新增通过、退步、两轮均通过与均未通过。点选指标和筛选条件可以查看具体回合。旧的 `#outcomes` 书签会进入模型对比。部署后请在已打开的标签页按 Ctrl+R，一次性加载新的页面脚本。

**训练调参。** 进入「训练调参」，选起始模型，设置目标总轮数、每轮更新步数和每次更新的 batch size。这三个数分别控制采样/拟合循环次数、每轮梯度更新次数，以及一次梯度更新抽取多少行示范。编辑和保存草稿都不会启动训练。GPU 空闲时才可明确启动独立实验；如要基于原长训继续实验，可选其已经完成并校验的轮次，原目录和断点保留。

三个结果奖励作用于 DAgger 的模仿损失：训练种子在采样时达到“曾拿稳”“结束仍稳持”“整颗转动”中的哪一项，就加上对应系数。基础权重为 1，然后在训练批内归一化；没有该结果的样本不获对应加成。这不是 PPO 的逐步奖励，调高权重也不自动降低验证门槛。阶段权重可以单独调节，闭环验证种子不参与梯度更新。

对用新版可调引擎启动的实验，面板区分草稿、待生效和本轮已用配置。提交后在下一轮开始时生效；恢复中断轮仍使用它已冻结的参数，便于复现。旧版长训没有轮间读配置的入口，所以保留只读。

**归档回放、CPU 推理。** 提供现有 90 毫米魔方的两个真实对照种子 21611、21612。三维视图按实测位姿绘制关键部位，是几何示意，不是相机录像。可播放、逐帧、拖动时间轴、变速、缩放和切换视角。选择模型和帧，点击“运行当前帧”可计算 28 个左侧关节目标，同时比较归档模型输出及实际下发角度。计算用决策之前的观测；换模型不会改写已经发生的轨迹。

**独立闭环推演。** 推理页另设“新模型闭环回放”。仅手动点击才申请运行；训练或 GPU 忙时不排队。使用正式验证的四个种子，从头运行冻结模型和物理控制循环，记录第一条环境的运动。模型控制左侧，右手和阶段仍使用原脚本。结果独立于长训，不覆盖训练权重和旧轨迹。单层拧动不是这一策略的训练目标。

训练监控、训练调参、归档回放和 GPU 推演分别独立；启动面板不启动训练或仿真。测试（不启动 Isaac）：

```bash
python -B -m unittest discover -s cube_dashboard -p 'test_*.py'
```
